# AsterHub 更新记录

## 0.4.3.5 · 2026-11-13

### 改进

- GPU 分析支持汇总全部显卡，进程列表显示可用路径及所属显卡标志。
- 分析结果复开优先显示缓存，减少重复加载；网络速率和区间流量自动切换合适单位。
- 任务列表支持清除已结束任务；下载校验完成后，点击“安装并重启”直接安装。

### 修复

- 修复 CPU、GPU、内存和网络分析区间拖动不跟手、松手跳动的问题。
- 修复内存区间比较在邻近采样缺失时进程闪现或丢失的问题，并标明实际采样时间。
- 修复 GPU 历史快照动画、任务栏设置切换和资源详情入口的显示问题。
- 系统内存区域分别显示可取得的真实读数、变化或执行状态，避免混淆释放量与进程归属。

- 任务栏监测改为直接拖动实时预览：逐页配置两格或四格，独立选择名称、数字和图形的顺序。
- 逐格迁移并保存任务栏布局，保留原有两列的坐标和空位，旧六格第三列的组合留在组件库；拥挤时临时简化显示，空间恢复后还原。
