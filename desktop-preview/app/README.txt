AsterHub · 连接设备，看见运行。

版本 0.3.0-preview.4，Windows 工作台公开预览版。

支持本机及多设备 SSH 监控、持续记录、历史与进程快照、主题、经典/趋势 GPU 卡片。修复历史黑屏、启动白屏和偏好设置分类切换跳动；连接测试、底部间距和负载配色已调整。网络与存储页面显示真实可用指标，缺失指标明确标示。

已恢复多标签 PowerShell / SSH 终端、终端字体设置、双栏文件复制传输、检查更新和反馈建议。文件和文件夹复制保留源文件，支持进度、取消与受限撤销；跨栏拖放为复制。Windows 外部拖入不能取得完整路径时，请使用文件或文件夹选择器。撤销仅删除本次新增且未变化的文件，不恢复已覆盖文件。

GPU 详情支持展开完整进程命令，结束进程前需确认并核验身份。历史快照仅用于查看。

默认关闭主窗口会收起到托盘并继续记录；双击托盘图标重新打开，在托盘菜单选择“退出 AsterHub”才停止程序。

偏好设置保留应用、确定、取消，并提供外观、动效、字号、密度、采样、历史保留、窗口与托盘、终端、更新和反馈。开机启动默认关闭。迷你监控尚未完成迁移，需要时可保留原稳定版。

预览更新采用固定发行方地址，验证签名与安装包后可安装并重新启动；请先完成或取消活动文件传输。本版与原稳定版独立安装、独立保存数据，不自动迁移连接凭据。Ubuntu 维持独立版本。

个人配置与历史默认位于 %LOCALAPPDATA%/AsterHub/Preview1；卸载保留这些个人数据，只删除程序自身的文件和启动项。

运行环境：Windows 10 1809+（x64），.NET Framework 4.7.2+，Microsoft Edge WebView2 Runtime。缺少 WebView2 时安装程序调用 Microsoft 官方联网引导器。标题栏精确配色已在 Windows 11 验证，其他 Windows 版本仍需兼容验证。
