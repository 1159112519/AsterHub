AsterHub · 连接设备，看见运行。

版本 0.3.0-preview.3，Windows 迁移预览版。

支持本机及多设备 SSH 监控、持续记录、历史与进程快照、主题、经典/趋势 GPU 卡片。Preview 3 修复单卡挤压、下拉菜单、原生标题栏、字号与实时曲线动画；概览各类资源以原位浮层展开。

已恢复托盘常驻。默认关闭主窗口会收起到托盘并继续记录；双击托盘图标重新打开，在托盘菜单选择“退出 AsterHub”才停止程序。

偏好设置提供外观、动效、字号、密度、采样间隔、历史保留策略、窗口关闭/最小化行为、启动后进入后台与当前用户开机启动，以及应用/确定/取消。开机启动默认关闭。

尚未迁移完成：终端及终端字体设置、文件传输、迷你监控、反馈和自动更新。需要这些功能时请继续使用原有正式版；本预览版独立安装和存档。

网络与存储的扩展交互设计原稿独立提供，其中示例指标没有混入本程序真实采样。

当前用户安装在独立的 AsterHub Preview 目录。个人配置与历史默认位于 %LOCALAPPDATA%/AsterHub/Preview1；卸载保留这些个人数据，只删除程序自身的文件和启动项。

运行环境：Windows 10 1809+（x64），.NET Framework 4.7.2+，Microsoft Edge WebView2 Runtime。缺少 WebView2 时安装程序调用 Microsoft 官方联网引导器。标题栏精确配色已在 Windows 11 验证，其他 Windows 版本仍需兼容验证。
