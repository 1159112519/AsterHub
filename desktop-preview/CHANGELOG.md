# AsterHub Windows 预览版更新日志


## 0.3.0-preview.23 · 2026-11-04

- 网络页可测本机下载、上传和 UDP 探测，支持自动选节点、切换速度单位和查看记录。
- 更换启动画面及应用图标，更新后启动时刷新 Windows 任务栏图标。
- 历史曲线在采集来源切换时优先使用连续记录，有可用补采数据就接续，实际缺测仍保留断点。
- 每台设备独立记住上次使用的页面和选项；切换回来可继续查看原来的扫描结果和历史范围。
- 更新在后台下载，可取消和继续；完成后由你选择安装。磁盘扫描入口可直接返回任务，查看进度。
- 历史支持自定义起止时间，长时间范围打开更快；移除重复的设备配置，保留当时的进程和显存。
- 内存清理可保留指定进程，清理记录按日期查看；自动清理的数值支持滚轮选择。
- 修复启动和历史浮层的清晰度、图标切换、设置布局与字体选择；统一侧栏和常用控件对齐。

## 0.3.0-preview.22 · 2026-11-03

- 加快检查更新，自动使用先响应的官方地址，减少网络波动时的等待。
- 安装包支持分段并行下载和断点续传，连接中断后可重试继续，避免重复下载。
- 下载完成后仍校验签名与完整性，再自动安装并重启；保留完整内置字体。

## 0.3.0-preview.21 · 2026-11-03

- 精简关于页面，移除字体说明，保留程序内置字体与离线显示支持。

## 0.3.0-preview.20 · 2026-11-03

- 中文界面统一采用内置 HarmonyOS Sans SC，英文与数字保留 Inter；离线和未安装该字体的电脑也可正常显示，统一按钮文字对齐。

- 存储工具现在可直接选择整块磁盘或单个文件夹，显示实际盘符和容量；路径选择窗口在切换模式时保持固定尺寸。
- 文件树以不同图标区分文件和文件夹，仅文件夹显示展开箭头，文件可以直接查看详情。
- 内存清理增加系统缓存范围反馈，选择缓存时显示对应区域，不再让进程列表造成误解。
- 图标与皮肤只显示预览及选中标记，移除可见编号与名称；调整设备弹出列表的行内对齐。
- 优化 Windows 小尺寸托盘状态圆点，保持不同显示缩放下的圆形轮廓。
- 启动更新提示跟随当前皮肤，直接下载、校验并自动安装；占用率进度条随读数平滑加深，低值更轻、高值更清晰。

## 0.3.0-preview.19 · 2026-11-03

- 本机 CPU 与内存刷新默认改为 2 秒，可在设置中选择 0.5–10 秒；快速刷新时数字直接更新，其他频率下平滑过渡并及时结束。
- 修复不同采样间隔交接时曲线出现假断口；简化内存影响预览，移除重复的记录与频率提示。
- 新增九套可独立选择的图标与皮肤，支持深色、浅色或跟随系统；经典黑及原有外观保留，窗口、托盘与终端同步适配。
- 统一原稿字体与存储标签层级，修正侧栏品牌居中；冷启动先显示品牌载入页，修复偶发透明空白与初始化等待。
- 磁盘空间分析采用从方块原位展开的目录动画，返回时收回到原位置；左侧目录导航保持相同节奏，并清晰区分文件与文件夹。
- 存储与内存工具统一顶部入口，保留扫描结果、当前目录与浏览位置，切换页面后可继续操作。
- Windows 本机新增内存清理，可选择低优先级待机缓存、全部待机缓存或进程工作集，执行前确认范围；进程工作集整理不会结束进程。
- 内存清理显示当前进程、完整路径、权限状态及操作记录，悬停和选择范围时联动标记相关区域。
- 新增默认关闭的内存自动策略，可设置占用阈值、持续时间和间隔；仅在 AsterHub 运行期间按所选范围执行。
