# AsterHub Windows 预览版更新日志

## 0.3.0-preview.15 · 2026-11-03

- 存储页面优先显示磁盘监控，空间分析和大文件清理集中放在下方工具区。
- 工具入口新增轻微悬停反馈，进入和返回保持连续过渡，返回时保留原来的浏览位置。
- 统一扫描等表单的内容边距、字段间距和底部操作区，改善不同窗口尺寸下的排列。
- 改善菜单与对话框嵌套时的关闭和键盘操作，保留五套皮肤及减少动态效果设置。
- 优化历史查询切换和后台任务状态读取，及时释放过期等待及已关闭终端的索引。

## 0.3.0-preview.14 · 2026-11-02

- 新增磁盘空间分析和大文件清理，可从存储页面进入独立工具；支持本机与已配置的SSH设备。
- 文件夹大小以面积图显示，支持分层浏览、搜索、悬浮详情及列表；后台扫描可暂停、继续或取消，期间可使用其他页面。
- 支持复制文件和文件夹，同名项目保留两份；文件可移入AsterHub回收区并恢复，不会自动清空回收区。
- 终端名称创建后固定，关闭其他标签不会重新编号；新增重命名、拖动排序、内容搜索、多行粘贴确认和独立配色预览。
- 桌面快捷方式、任务栏、窗口与安装包统一使用透明轮廓图标，保留六种图标与五套独立皮肤。

提示：扫描显示文件逻辑大小；移入回收区仍占用磁盘空间。远端是否占用文件无法完全确认，操作前需自行核实。Ubuntu桌面版继续保持0.1.3。

## 0.3.0-preview.13 · 2026-11-02

- 新增六组应用图标，可在外观设置中选择，重启后统一应用。
- 保留经典黑皮肤，新增暮蓝，调整松林、深海和瓷白皮肤，统一窗口、菜单与输入控件的配色。
- 图标与皮肤独立设置，侧栏和关于页面使用透明标识。
- 放大托盘图标的有效轮廓，按 Windows 缩放选择清晰尺寸，改善小图标偏小的问题。
- 图标更换支持直接重启；进行中的文件任务会保留，终端会话在确认后断开。

## 0.3.0-preview.12 · 2026-11-02

- 修复文件列表选择框被列宽调节区域遮挡的问题，保留其他列的宽度调整。
- 调整顶部标题对齐与底部资源栏高度，减少重复读数和频率说明，改善窄窗口显示。
- CPU 当前速度采用支持的实时测量；GPU 显存频率在设备支持时显示。
- 加快历史记录加载后的时间范围切换，连续切换时取消过期请求。

## 0.3.0-preview.11 · 2026-11-02

- 近期更新集中展示最近三个版本，修复说明与记录数量不一致的问题。
- 修复窄窗口下底部资源栏的标题和容量文字被裁切的问题。
- 包含 preview.10 的字体、设备排序、表格列宽、GPU 排版、底部曲线和双端文件传输改进。

## 0.3.0-preview.10 · 2026-11-02

- 放大辅助文字，统一字号层级与滚动条样式，改善不同窗口大小下的阅读体验。
- 设备列表采用更紧凑的排列，支持拖拽排序并记住顺序，避免误选中文字。
- 表格支持拖拽调整列宽，也可用方向键微调，并记住各表格布局。
- 优化单张 GPU 卡片的空间分配；详情中频率、温度、功耗和风扇采用统一排列。
- 精简重复的显卡数量说明，放大 CPU 主读数。
- 修复底部资源读数位数和单位变化时，邻近曲线跟着移动的问题。
- 文件双栏可独立选择本机或已添加的服务器，支持服务器之间复制；确认时清楚显示来源和目标设备。
- 服务器之间复制通过本机中转，需保持程序运行及两端连接；保留取消、覆盖确认及撤销新增文件功能。

## 0.3.0-preview.9 · 2026-10-30

- 修复采集耗时较长时，实时曲线被误画成断段和散点的问题；真实缺失仍保留断点。
- 改善历史 GPU 曲线切换与时间点选择的响应，读取快照后可直接查看当时进程；完整列表按需展开。
- 修复概览 GPU 进程数量与详情列表不一致，汇总详情覆盖全部显卡，单卡详情仍按卡显示。
- 修复主图、详情浮窗和底部资源曲线向左移动时，左边缘短暂缺失的问题。
- 改善网络小曲线向左推进和纵轴变化的平滑度；统一底部资源读数的字号，频率随采样平滑更新。
- 图表范围选项移到标题右侧；移除 CPU 详情中的系统信息和内存页面中无关的处理器信息。
- 放大设备名称及部分正文，统一 GPU 进程行对齐，放大进程信息并收紧结束按钮，保留执行前确认。
- 精简关于页面，放大版本号，整理三个版本与帮助入口；反馈保持为独立分类。
- 文件双栏底部复制操作采用对称排列。

## 0.3.0-preview.8 · 2026-10-30

- 修复资源详情浮窗中的容量文字间距，减轻范围与时间控件的底色；浮窗优先在内容区右侧展开。
- 精简资源概览，集中显示五类资源摘要；调整网络与 GPU 的位置，移除重复的显卡区域和进程列表。
- 恢复 GPU 页面结束进程入口，执行前核验身份并要求确认。
- 统一底部资源栏辅助文字的字号，放缓收起与展开的非线性动画。
- 终端新增按钮紧随最后一个标签，标签右键支持关闭当前、其他或全部终端。
- 改善历史 GPU 指标切换的响应速度，新增指标滑块和时间范围切换过渡。
- 整理关于与更新页面，增加主动打开的最近更新记录，保留启动自动检查和反馈入口。
- GitHub 项目更名为 AsterHub，新版本使用更新后的官方地址。

## 0.3.0-preview.7 · 2026-10-30


- 新增“启动时自动检查更新”开关；启动时静默检查，发现新版本后询问，确认后自动下载安装并重新启动。
- 改善官方更新连接的可靠性；下载与安装操作固定在版本状态旁，长说明不再把按钮挤到下方。
- 修复切换设备后终端仍显示或操作上一台设备的问题，保留各设备自己的会话与输出。
- 资源详情浮窗将纵轴范围与最近时间并排显示，统一字号与尺寸，避免曲线提示遮挡操作。
- 重新整理资源概览，集中显示主机状态、整机配置与 CPU、GPU、内存、网络、存储关键读数。
- 修复内存百分比裁切，内存页面仅显示内存相关信息；底部存储使用全部存储卷的汇总口径。
- 底部资源栏补充频率、显存和容量信息，在资源概览自动平滑收起；支持的设备显示实际 CPU 与 GPU 频率。

## 0.3.0-preview.6 · 2026-10-30

- 连接中断时保留设备信息与上次读数，显示暂停更新状态；恢复连接后继续采样。
- 打开程序即可看到资源卡片，尚未获取的读数显示为“—”。
- 实时曲线从右侧加入新数据并向左推进；历史中的数据缺失时段不再连线。
- 曲线补充纵轴单位，可选择自动范围或固定百分比范围；自动范围按峰值取整。
- 合并关于与更新页面，减少重复入口。
- 调整底部资源栏的间距和选中效果，让数字与趋势更容易对照。
- 改善资源详情浮窗的位置与层次，CPU 核心负载变化更平滑。
- 改善 SSH 采样连接的复用与重连等待，减少重复建立连接。

## 0.3.0-preview.5 · 2026-10-29

- 修复 CPU 核心数量较多时，缩小窗口出现重叠的问题，核心网格随宽度自动换行。
- 设置操作按场景显示：更新、关于和反馈不显示应用按钮；左下角统一提供关于与更新入口。
- 检查更新明确显示“当前已是最新版本”或可用的新版本，支持下载校验后安装并重新启动。
- 底部资源栏使用统一滑动选中背景，固定数字与趋势图槽位，避免读数变化挤动曲线。
- 修复打开 GPU 详情及采样更新时曲线中断、跳变；曲线、数字和进度条从当前显示状态连续过渡，统一非线性缓动。
- GPU 详情调整时间控件、进程操作字体和间距，完整命令横跨整行展开；结束进程仍需确认与身份校验。
- 正式采用折光银雾玻璃图标，覆盖程序、托盘、安装包、快捷方式和官网。
- 官网手机及平板补充随滚动进入的图文动效，保留减少动态效果选项。

Windows 预览通道独立升级，保留原有配置及历史。Windows 稳定版仍为 0.2.1，Ubuntu 保留 0.1.3。

## 0.3.0-preview.4 · 2026-10-29

- 修复打开历史记录时黑屏，增加页面异常恢复入口。
- 启动页面提前跟随主题背景，调整连接测试按钮居中和间距、底部常驻概览留白。
- GPU 详情支持展开完整进程命令；结束进程前确认并核验进程身份，历史快照保持只读。
- 利用率和显存按负载平滑变色，延续界面主题。
- 网络页接入接口切换、吞吐趋势、地址与链路信息、累计流量和错误计数。
- 存储页接入物理磁盘读取/写入、活动时间、队列长度、存储卷容量和容量趋势。
- 固定偏好设置框架，分类切换保持窗口位置；恢复终端字体、检查更新与反馈建议。
- 恢复多标签终端和可调整分栏的文件复制传输。

Windows 预览版独立发布；Ubuntu 保留现有版本。本版需要 WebView2 Runtime，不覆盖已有稳定版的数据。
