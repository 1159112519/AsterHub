# preview.19 到 preview.22 的升级入口

旧客户端只有9分钟单流下载且无续传；完整安装包在慢速链路中无法可靠完成。公开预览通道现在指向约40KB的升级引导。它内嵌经过发行密钥签名的完整22清单，使用新版分段下载器，校验完整包后将旧客户端传来的安装路径、父进程PID和重启参数原样交给Inno安装包。

- 完整安装包和GitHub已有签名清单保持不可变；通道清单单独签名，绑定升级引导的大小和SHA256。
- 内嵌清单资源必须由发布者签名；引导再次验证签名、目标版本及完整安装包名称；完整下载再次验证大小和散列。
- 正常版缓存固定在用户LocalAppData/AsterHub/PreviewUpdates/FullPayload；中断保留完成分段。
- QA缓存参数只在BOOTSTRAP_QA编译时启用。QA安装包、签名资源和缓存不得上传。
- 完整安装包仍可直接下载安装，不依赖升级引导。
- 构建：updater/build.ps1 -FullManifest updater/full-release.json -Output <output.exe>。
- 发布顺序：完整包与引导资源就绪→官网原子部署→官方通道签名清单快进更新；不覆盖已发布同名资源，不强推。
- 新版本需重新生成目标版本常量和内嵌签名清单；不会从命令行接受替代下载URL或禁用校验。
