# AQ Server 产品设计检查 · 2026-10-22

依据：当前运行版 WPF 截图（CPU、GPU、内存、设置、关于、托盘）以及用户认可的工作台结构。此次保留资源视图、导航、字体基线和非线性动画。

| 优先级 | 发现 | 对用户的影响 | 已落实 |
|---|---|---|---|
| 高 | 托盘依赖系统旧式菜单，信息密集且功能混杂 | 收起窗口后找不到主要操作，立即刷新无明确反馈 | 换成随主题变化的菜单：窗口/迷你监控、偏好/自启/关于、退出三组；移除立即刷新、终端等重复入口 |
| 高 | 悬停颜色可能被冻结 | 再次切换主题会异常 | 样式使用独立画刷副本，真实终端和主题回归通过 |
| 高 | 内部版本号直接用于公开发行 | 用户容易误判成熟度 | 对外 0.1.0，并明确早期测试阶段 |
| 中 | 关于里的更新文字行距紧 | 长说明难以扫读 | 14px、23px 行高；官网更新列表增加行距 |
| 中 | 安装器只部署自解压入口 | 安装、资源、许可证和维护边界不清晰 | 正式目录安装，免安装入口另行保留 |
| 中 | 官网移动端初稿文字过小 | 手机阅读吃力、触控目标偏小 | 正文 14px 以上，次要文字 11–12px，主要触控目标 42–46px |

托盘每项 40 DIP 高，统一图标槽、文字基线、两组分隔线和开机启动状态；Esc 和点击后关闭。持续采集是监控的默认行为，托盘无需提供手动刷新。

菜单交互、六项行为映射、启动状态、四种主题、Esc 与原生 popup 均有运行检查。桌面主界面和设置有布局/终端回归。官网已通过 TypeScript/Vite 构建与站点包测试，未在当前会话完成浏览器视觉验收；不能据此声称手机/平板已经实机验收。

截图在交付的审查目录中；官网使用匿名设备演示图，不包含真实用户名、服务器地址或运行记录。尚需其他 Windows 电脑安装验证、长时间多服务器采集测试、断线恢复与更新服务器联调，才适合正式 1.0 发布。
