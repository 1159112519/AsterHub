# 问题反馈与质量验证

通过软件内“反馈问题”提交使用问题，或在本仓库Issues中描述平台、软件版本、复现步骤、预期和实际结果。截图和日志应先遮盖密码、私钥、个人路径、服务器地址及其他私人信息。

缺陷处理包括复现、修复、对应平台回归和版本发布。只有实际验证过的行为才能记录为通过；静态检查、自动化测试与真实桌面验证分别说明。

Windows和Ubuntu独立发版。更新CHANGELOG、生成对应平台Release正文，并上传匹配版本的正式安装包与散列。CI候选制品不是正式签名发行包，QA安装器不得发布。发布步骤见RELEASING.md。

公开问题记录不包含内部协作人员、私有队列和未脱敏取证文件。安全问题使用仓库的私密漏洞报告入口，勿在公开Issue中发送凭据。
