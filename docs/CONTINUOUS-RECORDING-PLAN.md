# AsterHub 常驻采集服务方案

状态（2026-11-03）：Linux 独立采集服务 0.1.0 已实现并部署到已授权云服务器；Windows 桌面已接入读取。Ubuntu 桌面和 Windows 远程服务器适配保持暂停。完整 24 小时稳定性仍需实际运行时间验证。

## 目标和边界

当前 DeviceCapture 随桌面运行。新采集服务独立运行在被监控主机上：主机开机就记录，桌面退出或断网不影响服务器记录；关机期间不造数据。桌面继续沿已有 SSH 读取，不新增公网监听端口，不提供远程结束进程或文件写入接口。

Linux 首期采用 systemd、专属低权限账户、独立配置 `/etc/asterhub-agent/`、数据 `/var/lib/asterhub-agent/`，开机启动并在失败后重启。不得影响其他项目、训练进程、SSH、防火墙及现有 QA 服务；不会为了读取不可用指标自动提权。

## 采集与存档

记录 CPU 总量/逐核/频率、内存容量与占用、GPU 身份/利用率/显存/频率/温度/功率及有权限的进程元数据、网卡计数与速率、存储容量和读写活动。同时记录 UTC、启动周期、序号、采集间隔、耗时、能力列表和缺失原因。不记录凭据、终端内容或业务文件内容。

静态设备清单与瞬时读数分离；采集失败保留 GPU 身份与数量，标记读数过期。保留真正缺口，不补造连续曲线。

默认每 5 秒记录，保留 30 天，磁盘上限 1 GiB；分片轮换，启动恢复末条不完整记录。需验证资源开销和盘满行为。当前 Windows ArchiveStore 是 UTF-8 行记录与分时段 `.aqlog`；先定义版本化协议和转换器并验证兼容，不直接混入不同平台的格式。历史查询分页且有条数上限，多 GPU 不整天一次性传入 UI。

## 桌面接入

选择设备后探测服务版本和健康状态，展示最后采集时间。通过 SSH 有界读取、增量缓存，以主机身份/启动周期/序号去重；处理服务存档与桌面采样重叠。未安装服务时保留现有采集。安装、升级、卸载与删除历史分为明确操作，卸载默认保留数据。

## 逐步实现与验收

1. 独立采集程序、单次采集模式、版本化格式、CPU-only 和 1/8 GPU fixture。
2. systemd 及安装/升级/卸载，限定账户和目录。
3. 隔离验证桌面关闭后连续采集、断网恢复、重启恢复、盘限额、权限缺失。
4. Windows 桌面读取服务存档、去重和长历史性能。
5. 再在明确选定的云服务器部署，记录版本/散列，做真实时间跨度的持续运行验证。

服务运行或一张截图不能代表已通过 24 小时验收。Windows Service 平台适配另排，不以 Ubuntu 测试代替 Windows。

## 本轮落地与维护边界

- 源码 `agent/linux/asterhub_agent.py`；systemd 单元 `agent/linux/asterhub-agent.service`。Python 标准库实现，不安装额外第三方依赖。
- 二进制目录 `/opt/asterhub-agent/` 为 root 所有；服务账户 `asterhub-agent`，数据 `/var/lib/asterhub-agent/records.sqlite3`，默认每 5 秒采样，30 天及 1 GiB 上限。
- 无 HTTP/TCP 监听；桌面通过已保存并验证的 SSH 连接调用固定只读查询命令。命令不接受任意路径或 shell 片段。
- SQLite WAL 独立写入，记录压缩保存；摘要有界且保留峰值和真实间断；按实际时间读取详细快照。记录包含可见 GPU 计算进程，不包含凭据、终端内容或业务文件内容。
- 客户端历史页合并本机已存档数据与主机记录，避免同时采样的重复点；未安装或不可达时回退已有本地历史，不伪造记录。
- 其他 SSH 账户必须已有该数据目录的读取权限；本轮仅部署已授权云服务器，不代表所有添加的设备自动获得系统服务。Windows 常驻服务还未实现。
- 停止/升级只操作 `asterhub-agent.service`；卸载服务默认保留数据。禁止将卸载与清除历史合并。


## 本机轻采样与下一步远程方案

Windows桌面新增独立CPU/内存轻采样，默认500ms。它只调用系统计数接口，不触发WMI、GPU外部命令、SSH或历史写入。完整硬件/GPU/进程采集和历史记录仍按设置间隔运行。轻采样拥有独立源时间、序号、错误状态和有界短时环，数字/进度动画追随最新目标，不能冒充更多历史采样。

Linux远程实时数据优先复用常驻记录的1秒轻路径尚待实施：要拆开轻指标和GPU/进程慢查询、提供有界latest输出并复用持久SSH；旧服务当前5秒结果不得标成1秒。缺少有效常驻结果时仅启动单个轻量后备读取，恢复后关闭；禁止每秒重新启动完整采集包。远程服务默认采样间隔在本轮保持不变。
