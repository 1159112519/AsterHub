# AQ Server 0.1.3 interface

The selected reference is the Foundation Sunshine product family. AQ Server implements its warm neutral surfaces, grouped sidebar, filled selection, heading tile, aligned actions and restrained controls without copying its identity. Semantic icons come from Lucide under ISC; the quiet-rack application/tray mark is original authored vector geometry.

Five bounded footer groups belong to the selected device: CPU, GPU, memory, network and storage. Window resizing switches between five columns and three-plus-two rows. Labels, values and plots reserve stable geometry during number/unit animation. Network uses counter deltas on a per-device monotonic clock; unknown first/reset/reappearing-interface samples are not zero. Storage reports the system/root partition and lists actual volumes in the detail page.

Connected devices continue recording while another view or device is selected. Network and volume payloads are additive to the existing archive version. Older archives remain valid; absent telemetry remains unavailable. History snapshots display the new readings when present.

Resource chart/number/meter/page motion remains nonlinear. Charts honor reduced motion; hover shows actual timestamps and units. Linux hover restores a cached chart image rather than rebuilding all polylines for every pointer event.

Verification records distinguish synthetic layout renders, actual local/SSH reads, native Windows interactions and Ubuntu GTK/WebKit/Xvfb actions. Virtual display tests are not physical tray or desktop drag-out compatibility tests.
